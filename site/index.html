Bring Your Own Private LoRA

用你过去的博客与笔记，训练只属于本机的私有文风卡带

每个人的书面表达都有独特的用词习惯。Chime 内置本地隐私清洗器（自动剔除 API Key、邮箱、手机号与私密链接），只需三步即可把你自己的历史文章微调成 28L Rank-8 private_pack: true 私有卡带，仅挂载于本机 ~/Library/Application Support/Chime/packs/。 

# 1. 在本地扫描并脱敏你的历史 Markdown 笔记，生成训练语料与词频表
uv run --python 3.12 --no-project --with jieba --with pypinyin \
  python tools/prepare_pack_corpora.py \
  --personal-posts ~/Notes/essays --private-out /tmp/chime_private

# 2. 在本机 Apple Silicon GPU 上基于 28L Q4 流形训练 9.66 MB Rank-8 LoRA
uv run --python 3.12 --no-project --with torch --with safetensors \
  --with transformers --with mlx --with numpy \
  python tools/colab_train_loras.py \
  --q4-model-dir dist/base_neural --vocab dist/base_neural/vocab.json \
  --private-txt /tmp/chime_private/personal_lora_corpus.txt \
  --private-out-lora /tmp/chime_private/personal_lora.safetensors --steps 320

# 3. 打包并热安装至本机 Chime 扩展目录
chime pack build /tmp/chime_private/personal-style.imepack \
  --id personal-style --name "个人文风私有包" --routing always --private \
  --tsv /tmp/chime_private/personal_lexicon.tsv \
  --lora /tmp/chime_private/personal_lora.safetensors
chime pack install /tmp/chime_private/personal-style.imepack
