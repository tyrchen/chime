macOS 15+ · Apple Silicon · Apple Notarized · 100% Offline · MIT / Apache-2.0

把大模型塞进 64 MB 统一内存，按键零联网，卡带随插随用。

Chime 是一款专为 Apple Silicon 打造的端侧中文输入法。底层用 Rust 编写零拷贝双轨网格解码器（原生支持 Shift 中英切换 + 中/英双模式英文拼写自动纠错与退格撤回），二阶段在本地 Metal GPU 上运行 6 层 4-bit 蒸馏版 Qwen3（6 候选批处理 0.86 ms），并支持一键在线挂载 2 MB 级别的领域 LoRA 与 .imepack 扩展卡带及零遥测自动更新。

Base Model + Multi-LoRA Sidecar

为什么是「一个冻结基础模型 + 一组热插拔卡带」？

纯统计词库不懂语境同音词（如「保障权利」与「滥用权力」），而只挂 LoRA 却缺词条时，一阶段束搜索又无法召回《水调歌头》或《雨霖铃》的词牌领字。Chime 用 .imepack 卡带把零拷贝词典召回与低秩神经重排合二为一。

01 · Stage-1 Recall (< 0.8 ms)

CHIMED02 零拷贝多层词典栈

基于 mmap 直接映射 48 字节对齐的二进制词图，无需冷启动反序列化。支持 16 音节长诗整句解码、词牌短逗合并（念去去，千里烟波）、QWERTY 邻键与乱序纠错，以及 O(log C) 哈希续写链。

02 · Frozen 4-bit Base (64.2 MB)

6 层蒸馏版 Qwen3 常驻统一内存

从 28 层 Qwen3-0.6B-Base 经层间隐状态对齐与双温度 KL 蒸馏压缩至 6 层，词表裁剪至 24,576 个高频中英子词。全系统无论挂载多少个扩展包，基础权重只占一份内存。

03 · Multi-LoRA Sidecar (+0.04 ms)

按宿主 App 与上文动态路由权重

前向推理实时叠加 Δy = ∑ γₖ (x · Aₖᵀ) · Bₖᵀ。在 Ghostty / VS Code 中自动放大 tech-developer 权重；检测到古文虚词或诗词韵律时自动唤醒 classics-poetry。

Bring Your Own Private LoRA

用你过去的博客与笔记，训练只属于本机的私有文风卡带

每个人的书面表达都有独特的用词习惯。Chime 内置本地隐私清洗器（自动剔除 API Key、邮箱、手机号与私密链接），只需三步即可把你自己的历史文章微调成 private_pack: true 的私有卡带，仅挂载于本机 ~/Library/Application Support/Chime/packs/。 

# 1. 在本地扫描并脱敏你的历史 Markdown 笔记，生成训练语料
chime corpus-export ~/Notes/**/*.md -o /tmp/my_clean_corpus.jsonl

# 2. 使用 tools/colab_train_loras.py 训练 2 MB Rank-8 LoRA 后打包私有卡带
chime pack build /tmp/personal-style.imepack \
  --id personal-style \
  --name "个人文风私有包" \
  --routing always \
  --tsv /tmp/personal_words.tsv \
  --lora /tmp/personal_lora.safetensors \
  --private

# 3. 安装至本机 Chime 扩展目录并热重载生效
chime pack install /tmp/personal-style.imepack
